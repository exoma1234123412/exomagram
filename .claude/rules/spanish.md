# Spanish Copy Rules

UI is in Latin American Spanish. Use proper accents: día, número, también, categoría.

Keep these terms in English: Trust Score, Deep Work, Leaderboard, Standup, Kudos, Shoutout, War Room, Accountability, Heatmap, Focus, Feedback.

Use UTF-8 characters directly — never HTML entities (`&iacute;` → `í`).

Imperative mood for actions: "Registra", "Guarda", "Eliminar" (not "Puede registrar").
